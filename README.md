# Image Search App

A simple web app that searches and displays photos using the Unsplash API.

## Features
- Search photos by keyword
- Infinite "Show More" pagination
- Photographer attribution (per Unsplash API guidelines)
- Loading and error states
- Responsive grid layout

## Setup
1. Clone this repo
2. Copy `config.sample.js` and rename the copy to `config.js`
3. Get a free API key from [Unsplash Developers](https://unsplash.com/developers)
4. Paste your key into `config.js`:
```javascript
   window.CONFIG = {
     UNSPLASH_ACCESS_KEY: "your-key-here",
   };
```
5. Open `index.html` in a browser (or run via Live Server)

## Tech
- HTML, CSS, JavaScript (vanilla, no frameworks)
- Unsplash API

## Note
`config.js` is gitignored and never committed — each user creates their own from `config.sample.js`.
